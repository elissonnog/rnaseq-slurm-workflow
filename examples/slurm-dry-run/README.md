# Slurm Dry-Run Example

This example manifest is used by the smoke test to render a demo experiment directory and dry-run the numbered Slurm submission chain.

`SAMPLE_A`, `SAMPLE_B`, and `SAMPLE_C` are invented identifiers. No FASTQ files, patient metadata, research results, or institutional reference assets are included. The representative output in `expected_submission_plan.txt` demonstrates dependency ordering only.
