# Outputs

The Slurm workflow writes outputs under the analysis directory specified with `--project-dir`.

Key output locations:

- `fastqc_raw/` - raw FASTQ quality reports
- `trim_output/` - trimmed FASTQ files plus trim-associated FastQC reports
- `reference/star_index/` - STAR index generated by step 00 unless overridden
- `star_align/` - coordinate-sorted BAM files, BAM indexes, STAR logs, and `ReadsPerGene.out.tab` files
- `counts/featurecounts.txt` - featureCounts gene-level count table
- `multiqc/` - aggregated MultiQC report

Optional utility output:

- user-defined output table from `scripts/star_gene_counts_to_matrix.R`
